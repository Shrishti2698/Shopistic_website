[![GitHub Repo](https://img.shields.io/badge/GitHub-Shrishti2698/Shopistic__website-blue?style=for-the-badge)](https://github.com/Shrishti2698/Shopistic_website)

## Features

- **User Authentication:** Secure login using JWT (Access & Refresh Tokens)
- **Product Management:** Easily add, update, and delete products
- **Payment Integration:** Stripe API for smooth payment processing
- **Order Tracking:** Real-time updates on order status
- **Responsive Design:** Optimized for desktop and mobile viewing
- **Real-Time Data:** Seamless data fetching to keep your shop up-to-date

## Installation & Setup

1. **Clone the Repository**

   ```bash
   git clone https://github.com/Shrishti2698/Shopistic_website.git
   cd Shopistic_website
   ```

2. **Install Dependencies**

   For the **backend**:

   ```bash
   cd backend
   npm install
   ```

   For the **frontend**:

   ```bash
   cd ../frontend
   npm install
   ```

3. **Configure Environment Variables**

   Create a `.env` file in both the backend and frontend folders. Refer to the project documentation for the required environment variables such as database connection strings, JWT secrets, and Stripe API keys.

4. **Run the Application**

   For development purposes, run both the backend and frontend servers concurrently:

   ```bash
   # In the root directory
   npm run dev
   ```
